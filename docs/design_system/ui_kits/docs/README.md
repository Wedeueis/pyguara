# UI kit — Engine documentation

An API reference page for the Pyguara engine, in the Cerrado Day (light) theme.

**The repository ships no documentation site**, so the page chrome is new work. What *is* taken
from source and should stay accurate:

- The sidebar sections are the engine's real top-level packages: `ecs`, `graphics`, `physics`,
  `ui`, `ai`, `resources`, `scene`, `tools`.
- The code sample is the docstring example from `pyguara/ui/theme_presets.py`, unedited.
- The presets table carries the exact `primary`, `background`, border width and radius values
  from that same file.

Composes: `NavBar`, `TextInput`, `Button`, `Panel`, `Label`.
