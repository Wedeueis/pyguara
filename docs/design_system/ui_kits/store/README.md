# UI kit — Store page

An indie storefront product page for *Guará & Falcão*, dark theme.

**New work, not a recreation.** No store page exists in the source material, and this kit
deliberately does *not* reproduce any specific storefront's chrome or branding — it is a generic
product-page layout (gallery, pay-what-you-want panel, details table, devlog progress) rendered
in this design system.

Composes: `NavBar`, `Panel`, `Button`, `Label`, `ProgressBar`.
