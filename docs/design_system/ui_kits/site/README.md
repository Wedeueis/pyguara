# UI kit — Marketing site

A landing page for *Guará & Falcão*, in the Cerrado Dusk (dark) theme.

**This surface does not exist in the source repository.** The engine repo contains no website,
no marketing copy and no HTML. Layout and copy here are new work built strictly on this design
system's foundations and the provided art — treat it as a proposal, not a recreation.

Composes: `NavBar`, `Button` (sage/wood/ghost), `Panel`, `Label`, `ProgressBar`.
Art: `assets/sprites/logo-guara-falcao.png`, `scene-cerrado.png`, `hero-guara-idle.png`,
`sprite-falcao.png`, `items-gears.png`, `badge-pyguara-engine.png`.
