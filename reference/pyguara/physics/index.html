    pyguara.physics

    Physics subsystem.

    RapierEngine

    IPhysicsEngine over a native Rapier world.

    initialize 

    initialize(gravity: Vector2) -> None

    Create the world with gravity, in pixels per second squared.

    cleanup 

    cleanup() -> None

    Drop the world and every body in it.

    set_collision_system 

    set_collision_system(collision_system: Any) -> None

    Route collision begin, persist and end to collision_system.

    None stops reporting, which also stops paying for it.

    update 

    update(delta_time: float) -> None

    Step the world, then report the step's collisions in order.

    Events are reported after the step, not during it. A pair whose on_collision_begin returns False stops being resolved from the next solver step, not at once; it is still reported while it overlaps.

    create_joint 

    create_joint(
    body_a: IPhysicsBody,
    body_b: IPhysicsBody,
    joint_type: JointType,
    anchor_a: Vector2,
    anchor_b: Vector2,
    min_distance: float,
    max_distance: float,
    stiffness: float,
    damping: float,
    max_force: float,
    collide_connected: bool,
) -> Any

    Join two bodies with the constraint joint_type names.

    PIN is a rod at the anchors' current distance; DISTANCE is a stiff spring when its limits are equal and distance limits when not; SPRING rests at min_distance; SLIDER is distance limits; GEAR holds the relative rotation; MOTOR holds the relative spin at zero.

    Raises:

    Type Description
    TypeError

    If either handle is not one of this backend's bodies.
    NotImplementedError

    For a max_force on anything but a motor, which Rapier can limit only on a motor.

    CollisionSystem

    Bridges the physics engine's collision reports to the event system.

    The CollisionSystem maintains state about active collisions and triggers, ensuring that events are dispatched correctly and consistently. It's designed to be called by the physics engine's collision handlers.

    Attributes:

    Name Type Description
    _dispatcher

    EventDispatcher for publishing collision events.
    _active_collisions set[frozenset[str]]

    Set of entity pairs currently in collision.
    _active_triggers dict[tuple[str, str], bool]

    Dict tracking which entities are in which triggers.

    A Joint connects this entity's RigidBody to another entity's RigidBody, constraining their relative motion according to the joint type.
