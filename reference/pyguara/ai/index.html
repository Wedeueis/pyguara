    pyguara.ai

    AI systems for PyGuara.

    Provides behavior trees, finite state machines, steering behaviors, and other AI utilities.

    AISystem

    Updates AI decision making (FSMs/Trees).

    def move_to_target(context): ... context.position += context.velocity ... return NodeStatus.SUCCESS action = ActionNode(move_to_target)

    BlackboardCondition

    Bases: BehaviorNode

    Compare a blackboard value without writing a closure.

    One of the stock nodes a tree can be built from as data, since a closure cannot be serialised. The operators are equality and ordering; anything else is a ConditionNode.

    Example

    BlackboardCondition("health", "<", 20)

    CooldownNode

    Bases: DecoratorNode

    Refuse to run a child again until a delay has elapsed.

    The cooldown starts when the child finishes, not when it starts, so a long-running action is not cut short. A child that returns RUNNING is left alone.

    Reads context.dt, as WaitNode does, so time spent paused does not count.

    Example

    CooldownNode(5.0, ActionNode(cast_fireball))

    reset 

    reset() -> None

    Reset this node and its child, clearing any pending cooldown.

    tick 

    tick(context: Any) -> NodeStatus

    Tick the child unless the cooldown is still running.

    DecoratorNode

    Bases: BehaviorNode

    Base class for nodes that modify a single child's behavior.

    reset 

    reset() -> None

    Reset this node and child.

    InverterNode

    Bases: DecoratorNode

    Inverts child's result (SUCCESS <-> FAILURE).

    RUNNING is unchanged.

    Example

    inverter = InverterNode(ConditionNode(is_enemy_visible))

    Returns SUCCESS when enemy is NOT visible

    tick 

    tick(context: Any) -> NodeStatus

    Invert child's result.

    NodeStatus

    Bases: Enum

    Status returned by behavior tree nodes.

    ParallelNode

    Bases: CompositeNode

    Executes all children simultaneously.

    Returns SUCCESS if success_threshold children succeed. Returns FAILURE if failure_threshold children fail. Returns RUNNING otherwise.

    A child that has finished is latched: its result is remembered and it is not ticked again until this node itself resolves. latch=False re-ticks every child on every tick, for children that are all idempotent polls.

    Example

    parallel = ParallelNode( ... children=[move_to_target, scan_for_enemies, play_animation], ... success_threshold=2, ... failure_threshold=2 ... )

    reset 

    reset() -> None

    Reset this node, its children, and any latched results.

    tick 

    tick(context: Any) -> NodeStatus

    Execute all children in parallel.

    RandomSelector

    Bases: CompositeNode

    Try children in a shuffled order until one succeeds.

    A selector picks by priority, which makes a guard dog predictable. This picks by chance, which is what idle variation, attack choice and barks want.

    The order is reshuffled when the node starts, not on every tick, so a child that returns RUNNING keeps its turn rather than being abandoned mid-action.

    Example

    RandomSelector([bark, sniff, scratch])

    reset 

    reset() -> None

    Reset this node, its children, and the shuffled order.

    tick 

    tick(context: Any) -> NodeStatus

    Try children in a shuffled order until one succeeds.

    ReactiveSelectorNode

    Bases: SelectorNode

    A selector that re-checks higher-priority branches every tick.

    SelectorNode resumes at the child that was RUNNING, so a higher-priority branch that becomes viable mid-action does not take over. This node re-ticks from the top, so the first viable branch wins on every tick. The pre-empted child is reset().

    Example

    ReactiveSelectorNode([ ... SequenceNode([is_health_low, flee]), ... SequenceNode([is_enemy_close, attack]), ... ActionNode(patrol), ... ])

    ReactiveSequenceNode

    Bases: SequenceNode

    A sequence that re-checks its guards every tick.

    SequenceNode resumes at the child that was RUNNING, so a condition at the front is checked once. This node starts from the first child on every tick, so a guard holds for as long as the branch runs. When a failing guard pre-empts a RUNNING child, that child is reset(), so it does not resume half-finished later.

    Example

    ReactiveSequenceNode([ ... ConditionNode(is_player_visible), ... ActionNode(chase), ... ActionNode(attack), ... ])

    RepeaterNode

    Bases: DecoratorNode

    Repeats child N times or infinitely.

    Example

    repeater = RepeaterNode(ActionNode(patrol), count=5)

    OR infinite:

    repeater = RepeaterNode(ActionNode(patrol), count=-1)

    tick 

    tick(context: Any) -> NodeStatus

    Repeat child execution.

    reset 

    reset() -> None

    Reset repeater and count.

    SelectorNode

    Bases: CompositeNode

    Executes children in order until one succeeds.

    Returns SUCCESS if any child succeeds. Returns FAILURE if all children fail. Returns RUNNING if a child returns RUNNING.

    Example

    selector = SelectorNode([ ... SequenceNode([is_health_low, flee]), ... SequenceNode([is_enemy_close, attack]), ... ActionNode(patrol) ... ])

    tick 

    tick(context: Any) -> NodeStatus

    Try children until one succeeds.

    SequenceNode

    Bases: CompositeNode

    Executes children in order until one fails.

    Returns SUCCESS if all children succeed. Returns FAILURE if any child fails. Returns RUNNING if a child returns RUNNING.

    Example

    sequence = SequenceNode([ ... ConditionNode(is_enemy_visible), ... ActionNode(aim_at_enemy), ... ActionNode(shoot) ... ])

    tick 

    tick(context: Any) -> NodeStatus

    Execute children sequentially.

    SetBlackboard

    Bases: BehaviorNode

    Write a blackboard value and succeed.

    The write half of the authoring vocabulary -- enough to latch a flag, remember a target, or count something without a closure.

    Example

    SetBlackboard("alerted", True)

    tick 

    tick(context: Any) -> NodeStatus

    Set the value, failing only if there is no blackboard to set on.

    SucceederNode

    Bases: DecoratorNode

    Always returns SUCCESS regardless of child result.

    Example

    succeeder = SucceederNode(ActionNode(try_optional_task))

    Task failure won't stop parent sequence

    tick 

    tick(context: Any) -> NodeStatus

    Execute child and return SUCCESS.

    UntilFailNode

    Bases: DecoratorNode

    Repeats child until it fails.

    Example

    until_fail = UntilFailNode(ActionNode(collect_resources))

    Keeps collecting until resources run out

    tick 

    tick(context: Any) -> NodeStatus

    Repeat child until failure.

    WaitNode

    Bases: BehaviorNode

    Returns RUNNING for a specified duration, then SUCCESS.

    Example

    wait = WaitNode(duration=2.0) # Wait 2 seconds

    tick 

    tick(context: Any) -> NodeStatus

    Update wait timer.

    reset 

    reset() -> None

    Reset wait timer.

    Blackboard

    A shared memory container for AI decision making.

    Allows different parts of an AI (e.g., nodes in a Behavior Tree or states in an FSM) to read and write shared data without tight coupling.

    Retrieve a value from the blackboard.

    Check if a key exists.

    clear 

    clear() -> None

    Clear all data.

    NavMeshPathfinder

    A* pathfinding on navigation meshes, with string-pulling.

    Two stages. A* over the polygon adjacency graph finds which polygons to cross; the funnel algorithm then pulls a string through their shared edges to find the shortest route inside that corridor.

    get_neighbors 

    get_neighbors(node: GridNode) -> Iterator[GridNode]

    Yield valid neighbors.

    Diagonal moves refuse to cut a solid corner: both orthogonal cells flanking the diagonal must be walkable (in bounds and not a wall), matching the deleted GridMap's behavior -- an out-of-bounds flanking cell blocks the diagonal too, not just an actual wall.

    This is the largest Python cost in grid pathfinding, so it reads the grid directly instead of calling in_bounds and is_passable up to six times per candidate. The yield order is load-bearing: rust/src/flowfield.rs replicates it bit-exactly.
