    pyguara.studio.model

    The read model: what Studio and an agent see when they look at a scene.

    Three layers, sharing one value vocabulary:

    • values -- encoding component field values to JSON and back, shape- compatible with what SceneSerializer writes.
    • schema -- what a component's fields are, their types and whether they can be set. Drives the Inspector, the schema browser, and the JSON Schema an agent reads.
    • snapshot -- a scene at one instant, and the diff between two.
    • projectmap -- the budgeted inventory an agent reads first.

    UNENCODABLE_KEY module-attribute 

    UNENCODABLE_KEY = '__unencodable__'

    Marks a value that has no JSON form, holding its repr.

    Distinct from null, which means the field genuinely holds None.

    to_markdown 

    to_markdown(budget: int = DEFAULT_BUDGET) -> str

    Render the map as Markdown, within budget characters.

    Sections are emitted in priority order, whole or not at all -- a listing cut mid-item reads as a shorter list rather than a truncated one. When anything is left out the document says so, and says how much. A map that claims to be complete when it was truncated is worse than a short one.

    The counts section comes first precisely so that a budget too small for anything else still produces something useful.

    Parameters:

    Name Type Description Default
    budget int

    Characters to spend. Must be positive.

    		 DEFAULT_BUDGET

    Returns:

    Type Description
    str

    The Markdown.

    Raises:

    Type Description
    ValueError

    If budget is not positive.

    FieldSchema dataclass

    One field of one component.

    Attributes:

    Name Type Description
    name str

    The field's name.
    type_name str

    Its declared type's name, or the runtime type's name when there is no annotation.
    writable bool

    Whether assigning to it works. False for a derived property and for every field of a frozen dataclass.
    editable bool

    Whether Studio and an agent can set it from JSON. A writable field holding a texture is not editable: there is no JSON form for a resource handle to arrive as.
    default Any

    Its default, encoded, or None when it has none.
    has_default bool

    Whether default means anything -- distinguishing "defaults to None" from "has no default".
    doc str | None

    The property's docstring, where there is one.
    enum_values tuple[str, ...]

    Every accepted value, when the field holds an enum. Carried on the field rather than looked up later because this is the one piece of information an agent cannot guess and cannot discover from an error it has not made yet.
    derived bool

    Whether the field restates state stored elsewhere. Shown in an inspector, skipped by a snapshot -- see _DERIVED_FIELDS.

    decode 

    decode(value: Any, target_type: Any = None) -> Any

    		 required
