    pyguara.scene

    Scene management and transitions.

    Scene

    Bases: ABC

    Abstract base class for all game scenes.

    Manages the lifecycle of a specific game state (Menu, Gameplay, etc).

    Owns its own world: entity_manager and system_manager are private to this scene, so a scene pushed over another (e.g. a pause menu) never sees or affects the entities/systems underneath it. resolve_dependencies() populates system_manager with the five engine systems (Tween, Steering, AI, AudioSource, Animation -- priority band 100-399) plus camera and render_system, all live before on_enter() ever runs.

    resolve_dependencies 

    resolve_dependencies(container: DIContainer) -> None

    Call by the Application/SceneManager to inject the container.

    Builds this scene's engine systems, camera, render system, prefab factory, and DI scope (self.scope, for resolving SCOPED registrations tied to this scene's lifetime) -- all live by the time this returns, before on_enter() runs. Override this if you want to grab additional services immediately; call super().resolve_dependencies(container) first so the engine defaults are in place.

    on_teardown 

    on_teardown(callback: Callable[[], None]) -> None

    Register a callback to run when this scene exits.

    For anything scene-lived that needs undoing: a spawned entity, an audio channel, a subscription on a dispatcher the scene does not own.

    Run by SceneManager, not by on_exit(), so a scene that overrides on_exit() without calling super() still gets them. Callbacks run in reverse registration order. One that raises is logged and the rest still run.

    Parameters:

    Name Type Description Default
    callback Callable[[], None]

    Takes nothing, returns nothing. Called exactly once.

    		 required

    run_teardown 

    run_teardown() -> None

    Run and drop every on_teardown() callback.

    Called by SceneManager._exit_scene(). Idempotent: the list is cleared first, so a scene re-entered after exiting starts empty rather than running the previous visit's callbacks again.

    on_pause 

    on_pause() -> None

    Lifecycle hook: Called when scene is covered by another scene.

    Override this to pause game logic, music, etc. when the scene is no longer the top of the stack. By default, disables this scene's own system_manager (a second, independent gate alongside SceneManager's pause_below skip).

    on_resume

    Override this to resume game logic, music, etc. when returning to this scene after a scene above it is popped. By default, re-enables this scene's own system_manager.

    fixed_update 

    fixed_update(fixed_dt: float) -> None

    Fixed-rate update for physics and deterministic game logic.

    Called at a fixed rate (default 60 Hz) regardless of display framerate. Override this method to implement physics, collision detection, and game logic that must behave consistently regardless of frame rate.

    Parameters:

    Name Type Description Default
    fixed_dt float

    Fixed delta time in seconds (e.g., 1/60 for 60 Hz physics).

    		 required
    Example

    Parameters:

    render 

    render(
    world_renderer: IRenderer, ui_renderer: UIRenderer
) -> None

    Frame render logic.

    The default submits every entity carrying a visible Sprite to self.render_system, then flushes. With a Transform, Sprite.position is an offset from it. If that Transform has interpolate=True, the position drawn is lerp(previous_position, position, self.render_alpha). An entity with only a Sprite is drawn at the sprite's own position.

    Override to add manual draws, calling super().render(world_renderer, ui_renderer) first.

    add_layer 

    add_layer(scene_name: str, order: int = 0) -> None

    Activate a scene as a persistent layer above the scene stack.

    A layer lives outside the stack, so switch_to() leaves it alone: a HUD can outlive a change of world scene.

    Layers draw above every scene in the stack and above an in-flight transition, in order then insertion order, and keep updating during a transition. pause_below does not apply to a layer in either direction; use pause_layer() to freeze one.

    Parameters:

    Name Type Description Default
    scene_name str

    Name of the registered scene to activate.

    		 required
    order int

    Render order among layers; lower draws first. A modal that must cover the HUD is a layer with a higher order.

    		 0

    Raises:

    Type Description
    ValueError

    If the scene is not registered, or is already in use as the current scene or on the stack -- one scene cannot be both, since each would enter and exit it independently.

    fixed_update 

    fixed_update(fixed_dt: float) -> None

    Fixed-rate update for physics and deterministic game logic.

    Called at a fixed rate (60 Hz by default) whatever the display framerate. For each active scene, in order:

    1. Snapshot previous_position for every Transform with interpolate=True, before any system moves it.
    2. Tick the scene's own SystemManager.
    3. Call the scene's fixed_update().
    4. Flush the scene's EntityManager.

    Parameters:

    Name Type Description Default
    fixed_dt float

    Fixed delta time in seconds.

    		 required

    alpha float

    How far the current frame sits between the last two fixed steps (accumulator / fixed_dt), for Transform.interpolate entities. Set on each scene as render_alpha immediately before that scene's render() runs, rather than threaded as a Scene.render() parameter -- every one of the 9 demos already overrides that exact two-parameter signature, so adding a third would force a mechanical change across all of them for a value only the base default combination uses.

    		 1.0
    before_each Callable[[], None] | None

    Called immediately before every scene's render(), bottom of the stack to the top. Application uses it to re-bind the world render target: a scene that runs a render-graph pass itself leaves that pass's output buffer bound, and without this the scene stacked above it would draw its whole frame into that buffer instead of the world -- which is how a garden pushed over its title screen drew nothing at all.

    		 None

    cleanup 

    cleanup() -> None

    Tear down every live scene, LIFO, exiting each exactly once.

    Persistent layers go first (they draw on top), then the current scene (entered last), then the stack top-down. A scene that a transition has started entering but not yet made current is included too, so an application shutting down mid-fade does not leave it holding its world.

    CircularWipeTransition

    Bases: Transition

    An iris wipe: a circular hole that closes on the centre and reopens.

    The scene stays visible inside a circle centred on the window. The circle contracts to nothing, covering the frame from the corners inwards, and then expands again over the new scene.

    The cover is drawn at config.color, opaque by default as in WipeTransition and SlideTransition. A translucent colour is honoured; see circular_cover_points.

    Attributes:

    Name Type Description
    segments

    Sides in the polygon approximating the circle. See DEFAULT_WIPE_SEGMENTS for why 64.
